# Java-calculator
A basic calculator I build from java
Java Calculator 🧮

A simple console-based calculator built using Java. This project performs basic arithmetic operations based on the user's choice.

Features

- Addition
- Subtraction
- Multiplication
- Division
- Remainder
- User input using "Scanner"
- Menu-based operation selection
- Basic division-by-zero handling
- Invalid choice handling

Technologies Used

- Java
- "Scanner"
- "switch-case"
- Variables and data types
- Conditional statements
- Arithmetic operators

How It Works

The program:

1. Takes two numbers from the user.
2. Displays a menu of operations.
3. Takes the user's choice.
4. Performs the selected operation using "switch-case".
5. Displays the result.

Example

Enter any two numbers:
20
5

Choose an operation:
1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Remainder

Enter your choice: 4

Division = 4

How to Run

Make sure Java is installed on your system.

Compile the program:

javac Calculator.java

Run it:

java Calculator
